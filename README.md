# Mina & Bit · Sıfırdan Al-Sat Botu

## Nasıl çalıştırılır?

1. [python.org](https://www.python.org/downloads/) adresinden Python'u indir ve kur. Kurulumda **"Add python.exe to PATH"** kutusunu işaretle.
2. Başlat menüsüne **IDLE** yaz ve aç.
3. **File › Open** ile `bot.py` dosyasını aç, **F5**'e bas.
4. Durdurmak için **Ctrl + C**.

Ek paket kurmaya gerek yok.
